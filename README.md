# ふたりの旅アルバム

旅行の写真をまとめて入れると、撮影日時と位置情報から旅ごと・エリアごとに自動で仕分けて、日本地図を写真で埋めていくアプリです。

## 置き方（GitHub Pages）
1. このフォルダのファイル（index.html / manifest.webmanifest / sw.js / config.js / アイコン3つ）を、GitHubの新しいリポジトリにアップロードします
   - index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png / apple-touch-icon.png
2. Settings → Pages で「Deploy from a branch」「main」「/(root)」を選んで保存します
3. 数分後に表示されるURL（https://ユーザー名.github.io/リポジトリ名/）をスマホのSafariで開き、共有ボタン →「ホーム画面に追加」

## 更新するとき
新しい版のファイルで上書きして（config.js は設定済みなら上書きしない） Commit し、1〜2分待ってから、アプリを完全に閉じて2回起動してください。

## ふたりで自動同期する（Firebase・無料）
どちらかが写真・メモ・コメントを入れると、相手のアプリにも自動で表示されます。2人のアカウント以外は見られません。

1. https://console.firebase.google.com を開き「プロジェクトを作成」（名前は自由。Googleアナリティクスはオフで可）
2. 「Authentication」→「始める」→「メール / パスワード」を有効にして保存
   →「Users」タブ →「ユーザーを追加」で、あなたと奥さんのメールアドレス・パスワードを登録
3. 「Firestore Database」→「データベースを作成」→ ロケーションは「asia-northeast1（東京）」→「本番環境モード」で作成
   →「ルール」タブに firestore-rules.txt の中身を貼り、2人のメールアドレスに書き換えて「公開」
4. プロジェクトの設定（歯車）→「マイアプリ」→ ウェブ（</>）アイコンでアプリを登録
   → 表示される firebaseConfig の { } の中身を config.js に貼り付け
5. config.js を GitHub に上書きアップロードして Commit
6. 2人のスマホでアプリを開き、「追加」タブでそれぞれのメールアドレスとパスワードでログイン

- 料金：クレジットカードの登録は不要です（無料枠のみ）。保存できるのは合計約1GB、写真で約3,000〜4,000枚が目安です
- ログインすると、それまでスマホに入れていた写真も自動でクラウドに送られます

## ふたりで共有する（ファイルで受け渡し・同期を使わない場合）
1. 2人のスマホとも「追加」タブの「ふたりの名前」を同じ順番にし、「このスマホを使うのは」で自分を選ぶ
2. 送る側：「追加」タブの「新しく追加した分を送る」→「送る」→ AirDropで相手を選ぶ
   - 旅ごとに送るときは、旅のページの「この旅を送る」
3. 受け取る側：AirDropのファイルは「ファイル」アプリに保存されます。アプリの「追加」タブ →「受け取ったファイルを取り込む」で、そのファイルを選ぶ
- メモ・コメントはどの送り方でも全部含まれ、相手の内容と合わさります（消えません）
- 削除した写真は相手側では消えません

## データについて
- 写真・メモ・コメントは、それぞれのスマホのブラウザの中だけに保存されます。GitHubやほかの場所には送られません
- 2台のスマホのデータは共有されません
- Safariの「履歴とWebサイトデータを消去」をすると、アプリのデータも消えます
